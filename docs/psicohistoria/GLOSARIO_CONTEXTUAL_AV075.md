# PSICOHISTORIA · AV-075 — Glosario emergente de conceptos del laboratorio

**20/10/2026.** Glosario central de 31 conceptos científicos y metodológicos, con explicación rápida y límite interpretativo. Aplica automáticamente a todas las vistas bajo `#view`, incluyendo componentes cargados posteriormente: Inicio, Explorador, Riesgos 2027, Evidencia, Mapa, Registro, Hitos, Ideas y Estudio audiovisual.

**Interacción:** hover en escritorio, tocar en móvil, foco/Enter/Escape en teclado, cerrar fuera. Popup único flotante a nivel de documento, evitando recortes por `overflow` de gráficos y tarjetas. El texto añadido se genera como nodos DOM mediante `textContent`; no se aceptan HTML no confiables, scripts, enlaces, formularios ni SVG como candidatos. Se limita a 6 conceptos por sección y 3 por nodo de texto para no saturar.

**Precisión:** «violencia estatal» describe el indicador UCDP con una parte estatal en conflicto, no cualquier violencia del gobierno; el umbral de 25 es país-año y no acredita el comienzo de una nueva guerra; el backtest con fuente revisada no equivale a datos disponibles en origen; 2027 permanece sin emisión prospectiva confirmada.

**Menos texto:** la cabecera del árbol conserva años y advertencia sobre la fuente; se resume la explicación de nodos, flujos y trayectoria, que ahora puede consultarse al pasar el ratón.

**QA:** definiciones verificables, coincidencias con acentos y límites de palabra, no duplicar componentes ni cambiar valores, soporte de vista dinámica, CSS local, suite UI y controles privados. No toca modelos, predicciones ni datos canónicos. Inspección visual autenticada queda pendiente tras despliegue.
