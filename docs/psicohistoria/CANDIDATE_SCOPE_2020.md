# Candidate source scope

UCDP monthly event files have different declared geographical coverage in 2018-2020. A global declaration does not establish negative country labels.
## Real-source observation, October 2026

UCDP's [historical download catalogue](https://ucdp.uu.se/downloads/olddw.html) declares regional, not global, coverage through Candidate 20.0.9 and global scope since 20.0.10. The September 2020 file has 809 events from 41 event-positive countries; October has 1,070 events from 46 event-positive countries. These are **not coverage denominators**. April 2020's geography conflicts between archive summary and codebook 1.2, so it remains unresolved. No negative labels, as-of vintage, or forecasting is authorized.
